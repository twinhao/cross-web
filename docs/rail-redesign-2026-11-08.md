# 收合側邊欄設計調整

依使用者提供的窄欄截圖，調整擁擠捲軸、重複院所圖示、分隔線及底部多顆帳戶操作圖示。

- 收合寬度改為 72px，功能操作區仍為 44px，沿用現有明暗主題與品牌圖示。
- 上方只留品牌，院所名稱保留於提示；功能圖示統一 20px，選取以實色底板及對比文字辨認，移除窄版左側藍線和橫向分隔線。
- 窄版底部只留帳戶入口，點開後可修改密碼或登出。Popover 使用現有 Bits UI；轉入密碼對話框時保留正確焦點，Escape 關閉帳戶選單後還原至入口。
- 一般高度不需捲動，短視窗仍保留原生捲動、鍵盤焦點及最後一項功能的可達性。展開與手機仍提供原有完整選單。

側邊欄七項操作驗收通過，涵蓋 733px 高度、420px 短視窗、收合偏好、提示、鍵盤、帳戶、密碼及登出。另外以實際滑鼠驗證示範頁開關帳戶選單，保留捲動位置與焦點。使用虛構 API，沒有操作真實帳號。

型別檢查、lint、建置及 Workers 打包通過。Snyk 掃描 438 份網站／側欄測試來源、286 份 Svelte 編譯副本，0 findings；來源雜湊一致，副本不含環境檔或憑證。

最終完整回歸 429 項：428 通過、1 項既有遠端環境檢查略過、0 失敗。正式驗收結果另記於跨專案發布紀錄。
