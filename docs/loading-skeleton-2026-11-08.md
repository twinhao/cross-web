# 載入骨架補齊

初次載入使用與內容相近的骨架，不以空白、單行文字或單一轉圈作為整頁等待畫面。

- 後台確認身分時提供外框、側欄、標題及內容骨架；院所資料依頁面呈現卡片、表單、清單或月曆。身分未確認前不顯示真實帳號、院所資料或可操作入口。
- 常用時段對話框使用表單骨架。預約、排班與叫號的背景更新維持既有資料保留策略，不因這次更新改變查詢或操作權限。
- 會員預約、預約對象、收藏、帳戶設定與預約詳情補齊登入守門骨架；預約對象及詳情資料讀取也使用對應骨架。
- 登入、個人資料建立、預約結果、信箱驗證、首頁合作院所與候診看板補齊骨架，頁首確認登入時保留帳戶位置。
- 送出、儲存及登入中的按鈕保留原本處理中狀態。載入失敗仍顯示原有錯誤及重試，不用骨架掩蓋失敗，也不新增人為等待。
- 共用 `ContentSkeleton`、`MemberLoading` 與 `AdminLoading` 都使用現有 shadcn-svelte Skeleton。狀態具讀屏說明及 `aria-busy`，裝飾內容隱藏；共用 Skeleton 支援減少動態效果。沒有引入其他骨架套件。
- 骨架底色使用前景色的 10% 透明度，避免暗色模式的卡片與 `muted` 同色而看不出內容結構。
