# 側邊欄導覽優化

日期：2026-11-08（臺北）

## 操作調整

- 院所設定可展開基本資料、人員設定、服務項目與公告子選單，直接沿用原有工作區路徑及日期／人員銜接。
- 進入設定子頁時自動展開分類，選取狀態精確到子頁；父項顯示所在分類，避免同時標示兩個目前頁面。
- 收合模式使用現有 Bits UI Tooltip，滑鼠及鍵盤聚焦均能讀取功能名稱，Escape 可關閉。設定圖示保留目前設定子頁網址，展開／收合及重新整理保留原有側欄偏好。
- 一般院所員工不顯示受限的叫號／公告入口，手機第三個捷徑改為客戶。管理員保留完整入口；直接網址與後端授權仍沿用既有規則。
- 手機選單使用相同子選單與選取狀態，換頁自動關閉。桌面與手機的展開控制項關聯使用不同 ID，避免同頁重複。
- 縮減分組及品牌區留白，維持 44px 操作高度、亮暗色、長名稱截斷、可捲動功能區及固定帳戶操作。

## 驗證範圍

側邊欄五項操作驗收涵蓋桌面收合偏好、鍵盤換頁、子頁直接導航、提示文字及 Escape、360／768／1440px 亮暗色、手機關閉與旋轉、長院所名稱、短視窗、平台／院所情境，以及管理員／員工入口。受保護頁面的所有 API 使用虛構資料，沒有讀寫正式病患資料。

型別檢查、lint、正式建置與 Workers 打包通過。安全掃描包含 437 份網站與本次測試來源、285 份 Svelte 編譯副本，0 findings；來源雜湊與最終工作區一致。副本不含環境檔、憑證或其他子專案。
