# 完整示範院所

入口 `/demo`，使用者可切換院所門面、民眾預約及院所後台。首頁與導入頁提供入口，舊版示範門面另提供新版連結。

## 資料與操作

- 「澄光美學診所｜示範」是虛構品牌，沿用正式門面、相簿、預約流程及院所工作區元件。
- 初始提供專業版展示、人員、服務（含隱藏價格）、公告、未來排班、客戶與不同狀態的示範預約。
- `src/lib/demo/session.ts` 是瀏覽器分頁內的資料介面，不連線後端。選取時段會考量示範班表、休息、人員服務對應、休假及已有預約。
- 預約完成後可到後台查看同一筆資料；後台服務與相簿編輯可回到門面查看。切換視角及篩選不重置資料；只有明確重置或重新整理才還原。
- 模式使用 `mode=clinic|booking|admin|success`；保留後台原有 `view=list|day|week` 日曆參數，兩者不得共用。
- 身分與收藏使用獨立 context／實例，不儲存示範 token，也不清除真實登入資訊。
- 示範頁的 API 全部由前端介面處理，未知端點一律拒絕，禁止回退到正式 API；沒有通知、付款、帳號／密碼變更及第三方短連結解析等外部操作。
- 上傳圖片只使用本分頁的 object URL，不傳到網路，重置時釋放；重新整理後由瀏覽器釋放。
- 明確標示不提供醫療服務，不收費、不發送通知，並請使用者勿輸入真實個資；頁面與 HTTP 回應均禁止索引。
