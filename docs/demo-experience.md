# 完整示範院所

入口 `/demo`，使用者可切換院所門面、民眾預約、院所後台及候診看板。首頁與導入頁提供入口，舊版示範門面另提供新版連結。

## 捲動與導覽

示範使用瀏覽器原生頁面捲動，沒有額外的內層捲動區；頁內連結、返回及重新整理交由路由處理。頂部保留四種視角與簡短示範標示，手機以門面／預約／後台／看板縮短文字；完整說明由「示範說明」開啟。

導覽高度隨畫面尺寸量測，後台表頭、側欄及預約進度依實際高度固定。頁面捲動會避讓頂部與底部操作區；離開示範時還原原先的捲動留白。預約日期、人員、狀態等查詢參數改變時，不再強制將畫面捲回頂端。

## 資料與操作

- 「澄光美學診所｜示範」是虛構品牌，沿用正式門面、相簿、預約流程及院所工作區元件。
- 初始提供專業版展示、人員、服務（含隱藏價格）、公告、未來排班、客戶與不同狀態的示範預約。
- 報到只更新原預約，重送不新增資料。今日與預約詳情的入口會帶到同筆資料的「叫號與報到」；待報到與候診／服務分頁。先完成目前服務，再叫下一位；呼叫時核對預期客戶與人員是否空閒。省略核對參數的舊 API 格式維持相容。客戶名單支援姓名／電話等查詢、停用篩選及分頁。
- 常用時段可讀取、修改及重置；修改預設值不覆寫既有班表。所有設定仍只存在於本分頁。
- 現場頁可將叫號未到者標記過號，移至過號暫停名單，其他人接續服務；返回保留原號碼重新候診，不打斷目前服務，也不列為未到或完成。
- `mode=board` 的看板沿用正式看板元件。與本分頁後台共用預約狀態，切回看板立即讀取，每 10 秒在可見時更新；報到、叫號、完成、過號及返回均可展示。過號者不上板，姓名先在記憶體介面遮罩，回應不含預約 ID、全名或聯絡資料。使用同分頁切換；重新整理／另開分頁會建立新的示範資料。
- 今日保留原有四筆示範，另有近 90 天的 12 筆虛構歷史紀錄。`src/lib/demo/reporting.ts` 依目前資料計算近 7／30／90 天的預約、未到、回訪、來源與日／週／月趨勢，不包含未來預約。未到率分母沿用正式分析的已完成＋已取消＋未到；客戶檔案的未到率沿用已完成＋未到。
- 報到、開始／完成服務、過號與返回會留下狀態事件；重送不重複記錄。看診統計取末次開始到首次完成，等待取首次報到到末次開始；缺值與非正時長略過，單段封頂 6 小時，與正式計算規則一致。無紀錄顯示空狀態，不填固定平均值。
- 公開頁造訪只計本分頁實際開啟門面的日期，同一天重複切換去重；不是預設的行銷流量。有預約客戶數來自同區間的不重複客戶，與造訪分開。
- `src/lib/demo/session.ts` 是瀏覽器分頁內的資料介面，不連線後端。選取時段會考量示範班表、休息、人員服務對應、休假及已有預約。
- 預約完成後可到後台查看同一筆資料；後台服務與相簿編輯可回到門面查看。切換視角及篩選不重置資料；只有明確重置或重新整理才還原。
- 模式使用 `mode=clinic|booking|admin|board|success`；保留後台原有 `view=list|day|week` 日曆參數，兩者不得共用。示範的 `/display/{DEMO_ID}` 連結轉回 `mode=board`，不可導向真實看板端點。
- 身分與收藏使用獨立 context／實例，不儲存示範 token，也不清除真實登入資訊。
- 示範頁的 API 全部由前端介面處理，未知端點一律拒絕，禁止回退到正式 API；沒有通知、付款、帳號／密碼變更及第三方短連結解析等外部操作。
- 上傳圖片只使用本分頁的 object URL，不傳到網路，重置時釋放；重新整理後由瀏覽器釋放。
- 明確標示不提供醫療服務，不收費、不發送通知，並請使用者勿輸入真實個資；頁面與 HTTP 回應均禁止索引。
