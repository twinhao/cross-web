# 人員日曆 UI 調整

依使用者提供的截圖修正短預約卡片：原本 30 分鐘僅約 43px 高，卻顯示三行資訊，導致第三行時長被裁切。

- 卡片改為兩行：時間與姓名、服務與文字狀態，移除重複時長。高度不足 44px 時只顯示開始時間與姓名；完整時段、服務及狀態仍在標題、無障礙名稱及詳情。
- 每小時 96px，卡片維持時長比例，最低 24px。短卡片的顯示範圍也參與重疊計算，同一人員的重疊預約並排，後續非重疊區恢復完整寬度。
- 加入半小時淡格線，時間軸及人員標題於日曆內固定，去除 Card 多餘上下內距。卡片使用不透明的主題混色背景，避免格線透過文字區。
- 狀態保留文字及輔助色條；手機維持既有時間清單，週行程保留既有內容，沒有新增 UI 套件。
- 只調整呈現；日期、服務時長快照、角色權限、預約詳情及後端可用時段規則沿用原有流程。

`tests/admin-calendar.test.mjs` 包含分欄與相接時段、短預約、缺少時長的單元驗證，以及 15／28／30／60 分鐘卡片內容不裁切、重疊預約滑鼠／鍵盤開啟詳情、平板長文字與固定標題、暗色及手機清單驗收。所有 API 使用虛構資料，不操作真實病患或預約。
