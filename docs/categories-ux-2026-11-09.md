# 服務類別管理 UI 與操作流程

「系統設定」內的服務類別管理改為按看診、醫美、美容、其他切換，避免把四組長清單全部攤開。

- 頁籤顯示分類數量，選取類型保留於 `category_type` 網址參數，支援重新整理與瀏覽器返回；只有目前頁籤呈現控制項。
- 提供名稱搜尋、啟用狀態篩選、結果數量及清除入口。空類型與無搜尋結果分別說明下一步，新增與清除篩選各保留一個主要入口。
- 清單呈現名稱、啟用狀態及顯示順序。手機採緊湊排列，桌面呈現欄位標題；按鈕維持 44px 操作範圍，長名稱可換行。
- 新增時明示所屬類型、名稱長度、預設啟用與自動排在最後。空白名稱不能送出，同名提供提示而不擅自改變後端允許重複名稱的規則。
- 編輯可調整名稱、整數顯示順序及啟用狀態；類型與識別代碼維持原值。儲存期間保護關閉及重複送出，失敗保留輸入並將錯誤帶入視野。
- 成功後沿用後端回傳值更新清單，不為單筆修改重新顯示整頁骨架。分類字彙快取同步重新取得，保留目前內容；較慢的舊回應及重新取得失敗不覆蓋最後的有效內容。
- 刪除保留確認與失敗重試，提供「改為停用」替代。現有後端直接刪除分類，沒有院所引用檢查；介面明確提示需先確認使用情況，不再暗示後端會阻擋使用中的分類。
